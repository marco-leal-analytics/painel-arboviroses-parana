# Código da aplicação

- `bootstrap.R`: inicialização do ambiente e dos carregadores centrais;
- `packages.R`: catálogo e carregamento controlado de dependências;
- `data_loader.R`: leitura e validação dos dados;
- `modules/`: funções compartilhadas por módulos, quando necessário.

O ponto de entrada da aplicação é o `app.R` na raiz do projeto.
