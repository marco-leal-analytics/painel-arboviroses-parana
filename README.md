# painel-arboviroses-parana
Painel de monitoramento epidemiológico das arboviroses no Paraná, desenvolvido em parceria com a Universidade Estadual de Maringá e o Estado. A solução permite acompanhar casos, incidência, distribuição regional, situação epidemiológica e óbitos, apoiando a análise e vigilância em saúde.
